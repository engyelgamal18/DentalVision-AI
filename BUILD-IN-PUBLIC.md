# Building DentalVision AI
I recently finished building DentalVision AI, a project where I explored how object detection can be used with panoramic dental X-rays.

My goal was to understand the full process, from preparing and annotating the images to training the model, reviewing predictions, and checking the final results.

## One Decision I Made

One decision I made was to show the project step by step on the website instead of putting all the information on one page.

I wanted the project to be easy to understand, even for someone who does not know much about AI or dental imaging.

## One Limitation

One important limitation of this project is that the model was trained on a limited dataset.

Because of this, the model may not work the same way on different image qualities or patient cases.

This project is for learning and testing, and it should not be used as a clinical diagnostic tool.

## What I Learned

This project helped me understand that building an AI project is not only about training the model.

I also learned that preparing the data, checking annotations, reviewing predictions, and explaining the results are very important parts of the process.

It also helped me become more confident using AI tools while still checking and testing the work myself.

## Final Note

DentalVision AI was a good project for me because it helped me connect my dental background with what I was learning about AI.

I still have a lot to learn, but this project gave me a better understanding of how an AI project can be built, tested, and presented.
